### What the papers must clearly state
1. **Problem**: beginners find programming abstract and boring.
2. **Solution**: a platformer where typing Java variable lines changes the world.
3. **Objectives**: declare variables of each type; reassign an existing variable; read error messages.
4. **Target users**: beginner programming students; a session is about 10-15 minutes.
5. **Tools**: Godot 4.7, GDScript, Git/GitHub, Pixel Frog art assets, CC0 audio.
6. **Features**: Byte, terminal with step-by-step checking, 4 heroes, 7 rooms, hints and stars, manuals, save, sound.
7. **Scope and limitations**: only Level 1 is built (variables and data types); only Java-style variable lines.
8. **Future work**: levels for conditionals, loops, methods (asset folders for levels 2-4 already exist).
