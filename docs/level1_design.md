# The tutorial (was Level 1) – Pixel Adventure

Status: **built 2026-11-12** - `scenes/levels/level1/level1.tscn` (main menu Play starts it;
the level id is still `level1`). Update this file when the design changes.

The old Level 1 is now a **one-room tutorial**: its first room, where Byte teaches how the game
works. Its other lessons are in **Level 1 on Treasure Island** (`docs/level2_design.md`), which
the tutorial's CONTINUE button leads to.

## The tutorial room
One 44 x 21 tile room, about one screen: start, Byte's gate (`System.out.println`), the spike
corridor, the Variables manual chest, Chelzy's wall-jump shaft, the fruit gallery, and on the
plateau at the top right Sarah's rescue flag and the trophy. All 16 fruit are needed for both.
The level-complete screen says TUTORIAL COMPLETE!

### What Byte teaches (`scripts/levels/tutorial.gd`)
Each talk pauses the game and shows Byte in a dialogue box (Enter moves on); the camera glides
to whatever Byte is talking about. The talks are `ByteTalk`s (`scripts/ui/byte_talk.gd`), the same base
the rescue cutscene (`hero_cutscene.gd`) uses.

| When | Byte says |
|---|---|
| The level starts | who Byte is; A/D and Space; Sarah waits at her flag and needs all the fruit; the gate opens only for code; the chest has a manual (press F) |
| The chest opens | (the chest window's tip) click the book to put it in your hotbar |
| The book is in the hotbar | which slot; press its number to hold it, left-click to read, A/D turn pages, F/Esc close |
| The book closes the first time | manuals explain the code with an example; the last page's println line opens the gate (or, if it's open already, read a manual whenever you're stuck) |
| 1st wrong line (in the terminal) | wrong lines are fine; fix the first X |
| 3rd wrong line (in the terminal) | after the room's hint: SHOW ANSWER types the line but costs a star |
| The gate opens (after the terminal closes) | your first line of Java; how to wall-jump the shaft; stamina |
| After Sarah's rescue cutscene | next level you'll switch to her with code; touch the trophy |

The terminal's `wrong_try(room, tries)` and `closed` signals exist for these talks.

## Building and testing the tutorial
- The map is generated by `tools/build_level1.gd` - a **text map**, one character per tile
  (`#` ground, `B` building blocks, `=` bar, `f` fruit, `^` spikes (20 damage), `K` checkpoint,
  `h` chest; `s` start, `g` gate, `k` Sarah's flag, `G` trophy). Edit the map and re-run:
  `godot --headless --path . --script res://tools/build_level1.gd`
  (it **overwrites** level1.tscn, so don't hand-edit the scene unless you stop using the script).
  After adding a new `class_name` script, run `godot --headless --path . --import` once first.
- `tools/test_level1.gd` plays the tutorial (needs a window, not `--headless`):
  `godot --path . --script res://tools/test_level1.gd` - prints 26 PASS/FAIL checks, and saves
  screenshots of Byte's talks to the user data folder (`test_screenshots/`).

The old seven-room Level 1 (its maps, its 105 checks and this file's old room tables) is in git
history, commit 80011e1. Its lessons now live in Level 1 on Treasure Island: `docs/level2_design.md`.
